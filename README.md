# QIMMA HUB — مركز القمة للخدمات الجامعية

موقع عربي (RTL) لمركز خدمات جامعية: عرض الخدمات والقوالب والأسعار، استقبال الطلبات
مع الملفات المرفقة، متابعة الطلب برقمه، ولوحة إدارة كاملة.

## التشغيل المحلي

```
pip install -r requirements.txt
python run.py
```

- الموقع: http://127.0.0.1:8000
- لوحة الإدارة: http://127.0.0.1:8000/admin
- بيانات الدخول الافتراضية موضحة في `دليل-الاستخدام.txt` المحلي، ويجب تغيير كلمة المرور من الإعدادات بعد أول دخول.

بدون أي متغيرات بيئة يعمل الموقع بقاعدة SQLite محلية في `data/qimma.db`.
يمكن أيضاً فتح `تشغيل-الموقع.bat` من ويندوز.

## التقنيات

- FastAPI + Jinja2 + uvicorn
- SQLite محلياً، أو PostgreSQL (Supabase) عبر `DATABASE_URL`
- تخزين الصور والملفات: محلياً أو Supabase Storage عبر `SUPABASE_URL` و`SUPABASE_SERVICE_KEY`

## النشر السحابي

الملف `render.yaml` يهيئ خدمة Python مجانية على Render. خطوات الربط التفصيلية
موجودة في `دليل-الاستخدام.txt` (القسم 8).

## البنية

| المسار | الوظيفة |
| --- | --- |
| `app/main.py` | المسارات والصفحات |
| `app/db.py` | طبقة قاعدة البيانات (SQLite / Postgres) |
| `app/storage.py` | رفع الملفات إلى Supabase Storage |
| `app/seed.py` | البيانات الأولية: 5 أقسام و34 خدمة وقوالبها |
| `app/previews.py` | مولد نماذج القوالب (SVG) |
| `app/templates` | صفحات الموقع ولوحة الإدارة |
| `app/static` | التصميم والخطوط والصور |
